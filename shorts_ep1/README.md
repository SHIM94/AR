# 1억으로 20억 만들기 — 1화 쇼츠

재현형(스크립트 기반) 쇼츠 영상 프로젝트. 언제든 다시 렌더링할 수 있습니다.

## 결과물
- `1억으로20억_1화_shorts.mp4` — 1080×1920 / 30fps / 20초 세로 쇼츠
- `썸네일_1컷.png` — 썸네일
- `업로드_정보.txt` — 제목/설명/태그/고정 댓글/업로드 전략
- `내레이션_녹음용.srt` — 내레이션 5컷 타이밍(직접 녹음 시 참고)

## 구성 (20초 타임라인)
| 시간 | 씬 | 내용 |
|------|-----|------|
| 0–2s | HERO | `1억 → 20억`, "5년 안에, 진짜로." |
| 2–6s | THE MATH | 매년 필요 수익률 `+82%`, 버핏 20% vs 나 82% 비교 바 |
| 6–10s | BUFFETT | "돈이 적을 때가 제일 빠르다" 인용 |
| 10–17s | PLAN | ① 몰빵 ② 아무도 안 보는 종목 ③ 월급 말고 부업 |
| 17–20s | PROMISE | "성공해도 공개 / 망해도 공개" + 2화 예고 CTA |

하단에 `※ 개인 기록용 · 투자 권유 아님` 고지 상시 노출.

### 모션/그래픽
- 움직이는 배경: 떠다니는 금빛 파티클, 스크롤 그리드, 펄스 글로우
- 숫자 카운트업: `1억→20억`, `0→+82%`
- 애니메이션 차트: 상승 곡선(히어로·약속), 캔들스틱(버핏 씬)
- 네온 글로우 텍스트, 슬라이드 아이콘 카드, CTA 펄스

## 다시 만들기
```bash
python3 scripts/build_ep1.py
```
필요 요소:
- `ffmpeg`, `python3` (Pillow, numpy)
- `fonts/Pretendard-*.ttf` (한글 폰트)
- `assets/score_ep1.m4a` (배경 스코어 오디오)

영상 문구·색·타이밍은 `scripts/build_ep1.py` 상단 상수와 각 `scene_*` 함수에서 수정합니다.
2화도 같은 스크립트를 복사해 문구만 바꾸면 동일한 톤으로 제작할 수 있습니다.
